# Classification V2 scientific change-impact checklist

Complete this checklist for every feature or stage change. Record the
answer, evidence, reviewer and invalidated artifact hashes.

- [ ] Did the mathematical formula change?
- [ ] Did the coordinate system change?
- [ ] Did units change?
- [ ] Did normalization change?
- [ ] Did missing-value semantics change?
- [ ] Did zero-value semantics change?
- [ ] Did a validity mask change?
- [ ] Did an aggregation denominator change?
- [ ] Did temporal support change?
- [ ] Did the pair-reset boundary change?
- [ ] Did identity semantics change?
- [ ] Did tensor feature order or dimension change?
- [ ] Did a schema hash change?
- [ ] Did a threshold require recalibration?
- [ ] Did review semantics change?
- [ ] Did model eligibility change?
- [ ] Did leakage risk change?
- [ ] Which artifacts are invalidated?
- [ ] From which stage must the pipeline rebuild?
- [ ] Does paper terminology need updating?
- [ ] Are golden cases and tests updated?
