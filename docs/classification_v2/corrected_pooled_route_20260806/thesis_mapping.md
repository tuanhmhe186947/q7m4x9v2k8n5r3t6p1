## Claim language

The pooled reviewed population is the scientific population. Legacy and
additional material are complementary contributors. The route does not ask
which source is the better model-selection target, whether the sources are
identical domains, or whether every outer fold contains both sources.

The final thesis must report unsupported provenance/class/fold cells as
`NOT_ESTIMABLE`, preserve negative ablations, and state the single-camera and
single-pen external-validity boundary. A profile or screening layer must use
“behavioral deviation screening” or “potential behavioral anomaly detection,”
not a supervised abnormality or veterinary diagnosis claim.
